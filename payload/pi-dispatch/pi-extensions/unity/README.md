# Pi Unity 扩展

[![简体中文](.readme-assets/zh.svg)](README.md) [![English](.readme-assets/en.svg)](README.en.md)

独立配置：`~/.pi/agent/editors/unity.json` 或 `PI_UNITY_CONFIG`。

工具：`pi_unity_status`、`pi_unity_tools`、`pi_unity_call`。命令：`/pi-unity`。

查询与类型化的场景、资源修改通过现有原生 Unity Relay 执行，不开放任意 C# 执行接口。详见[配置、操作结构与边界](../EDITOR-BRIDGES.md)。
