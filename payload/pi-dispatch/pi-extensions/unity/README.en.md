# Pi Unity extension

[![简体中文](.readme-assets/zh.svg)](README.md) [![English](.readme-assets/en.svg)](README.en.md)

Independent configuration: `~/.pi/agent/editors/unity.json` or `PI_UNITY_CONFIG`.

Tools: `pi_unity_status`, `pi_unity_tools`, `pi_unity_call`. Command: `/pi-unity`.

Queries and typed scene/asset modifications use the existing native Unity Relay. Arbitrary C# is not exposed. See [setup, operation schemas and boundaries](../EDITOR-BRIDGES.md).
