## Default image workflow: image-prompt-review

- For every user request to generate or edit a raster image, or optimize an image prompt, load and follow the installed `image-prompt-review` skill by default. This includes image-generation tests, concept art, illustrations, and edits. Do not apply it to unrelated diagrams, code-only UI work, or quoted requests.
- Follow its current workflow: retrieve relevant YouMind references when applicable, present the complete versioned prompt and required references, and obtain explicit approval. The destination must be actual ChatGPT Temporary Chat. Use the supported hidden in-app browser to verify login and actual Temporary Chat, submit the approved prompt once, and return the verified generated image. The host app handles prompt review and browser orchestration only. Hidden browser operation is not a claim of an independent headless runtime. If browser access, login, generation or image retrieval is blocked, preserve the request and report that stage; provide a manual handoff when necessary. Do not substitute a saved Codex/projectless task, fork, or subsequently archived task. Prompt approval alone never authorizes those alternatives. Temporary Chat is not quota-exempt; do not promise zero usage.
- Only an explicit user instruction to bypass or change this workflow authorizes an exception (for example, "skip prompt review" or "generate directly without the plugin"). A generic request such as "generate an image", "test image generation", urgency, or silence is not an exception. Apply an exception only to the scope the user states.
- Do not silently substitute the built-in image tool, another plugin, API, CLI, or another task route. If the skill cannot be read or a required capability is unavailable, report the specific blocker and retain any prepared prompt. Distinguish optional retrieval failure (handled as the skill specifies) from missing workflow dependencies.
- The approved destination task executes the already-approved prompt once and must not recursively restart prompt review. Changes to the approved prompt, references, count, or destination follow the skill's reapproval rules.
- This is a user-level default for tasks loading this Codex home, subordinate to system/developer instructions and actual tool permissions. If a higher-priority requirement prevents this workflow, disclose the conflict and do not claim the plugin workflow ran. This file does not configure account-wide ChatGPT behavior or enforce a platform-wide interception.
