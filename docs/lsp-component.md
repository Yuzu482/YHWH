# YHWH LSP 组件说明

[English](lsp-component.en.md)

## 本次发布状态

YHWH v0.8.1 为私有仓库中的预发布。本次单独说明 LSP 的功能、来源和许可待确认项；未替换 LSP 实现，也未改变运行行为。该说明不代替上游许可证，不表示公开分发检查已通过。

## 提供哪些功能

YHWH 将代码查询接入统一治理入口。确定性 `lsp_request` 路径直接调用工具，不需要模型推理或 API key，返回结果区分实际语言服务器和 Tree-sitter 后端。

| 类别 | 当前入口 |
| --- | --- |
| 诊断与导航 | diagnostics、hover、definition、references、symbols |
| 编码辅助查询 | completions、code_actions；只返回查询结果，不执行代码操作 |
| 结构信息 | overview、search；由 Tree-sitter 相关实现提供 |

安装配置覆盖 Python、Java、JavaScript、TypeScript、C# 和 C/C++ 的语言服务。配置中包含服务不代表已在所有项目和目标机器上验证；结果取决于语言服务器安装、项目依赖、作用域和初始化状态。

## 来源与安装关系

- YHWH 自有网关、范围检查、沙箱调用和结果适配层采用 Apache-2.0；第三方代码与引用片段保留各自许可。
- 底层依赖固定为 `pi-lsp-extension@1.3.0`，源码提交 `5edc932d325b630483f84f7d7f038e88ceba1eba`。当前适配层直接调用其管理器、工具工厂及 Tree-sitter 模块；这不是独立重写版本。
- 发布资产包含 YHWH 脚本、锁文件与来源材料，不捆绑该依赖的完整 npm 目录或语言服务器二进制。安装过程中从上游下载依赖并应用补丁。
- 现有安装路径仍包含 LSP；单独编写说明并未把它变成可以完全跳过安装的可选模块。`-SkipWsl` 只跳过 WSL 配置，不是完整的 LSP 排除开关。
- 语言服务器、解析器和传递依赖分别适用自己的许可证。当前锁文件清单不是所有系统组件的完整许可证文本审计。

## 修改与执行边界

安装补丁禁止读取项目 `.pi-lsp.json` 作为可执行配置，并禁止自动发现 Lombok Java agent；Windows 完整补丁还加入隐藏子进程窗口及 C/C++/C# 服务配置。安装后的依赖带有 `YHWH-PATCH-NOTICE.txt` 修改说明。

确定性路径使用限定文件范围的只读沙箱，并检查任务清理结果。诊断必须实际收到语言服务器的诊断通知，不能把没有通知当作没有错误。无模型调用不意味着无需信任语言服务器或底层依赖，也不意味着已验证每种语言的所有功能。

已提交 [上游 Issue #14](https://github.com/samfoy/pi-lsp-extension/issues/14)，请求完整通知并确认是否覆盖 1.3.0。详情见 [核查与补齐记录](lsp-license-remediation.md)、[原始证据](../licenses/pi-lsp-extension-evidence.json)及 [第三方清单](../THIRD_PARTY.md)。

`Build-Release.ps1 -PublicRelease` 继续阻断。私有预发布、安装时下载和本说明都不能替代许可义务。后续获得上游确认或完成独立替换后，需要重新核查、验证并发布新版本。
