# 部署启动与完成信号

修复对象是宿主网关启动过程。模型任务、审查器和沙箱的回收规则不变。

## 已复现的问题

Windows 隔离实验中，PowerShell 的启动进程约 0.7 秒退出，退出码为 0，但输出管道直到后台服务被停止才关闭。调用方等的是 EOF，不是进程退出。因此有“安装成功、服务可用，外层部署仍不返回”的现象。

单层 Node 分离进程和直接日志文件实验约 0.8 秒完整返回，但嵌套 PowerShell 重定向仍失败。两次初始嵌套回归均为 19/20 通过，失败记录保留。不能据单层结果证明整个部署链通过。

最终 Windows 实现用 `STARTUPINFOEX / PROC_THREAD_ATTRIBUTE_HANDLE_LIST` 创建一个干净的启动器进程，只继承 NUL 输入和两个独立文件句柄。这个启动器再启动固定网关，外层管道不会传到服务。参考 [Microsoft 的句柄继承接口](https://learn.microsoft.com/en-us/windows/win32/api/processthreadsapi/nf-processthreadsapi-updateprocthreadattribute)。

## 入口和结果

宿主使用插件内 `scripts/start-gateway.mjs --settings-file <绝对路径>`；可选 `--timeout-ms` 为 1000–30000，默认 30000。`install/Ensure-SilentRuntime.ps1` 使用同一个入口，并保留原有互斥锁、端口检查、Tunnel 目标校验与认证方式。部署脚本启动或恢复网关时也应使用这个入口，不能继续内联 `Start-Process` 的旧启动方式。

设置中的解释器必须匹配当前 Node，网关脚本必须是相邻的固定 `gateway.mjs`，配置必须与 loopback 地址和端口一致。不提供任意程序、参数、运行时或远端 URL 入口；不是 MCP 工具。Windows 的额外桥接脚本固定启动相邻的同一个 Node 启动器，通过受限 JSON stdin 接收宿主数据，校验真实 Node 父进程。内部隔离标记只用于防止启动器递归，不能用作授权证明，宿主不得在外部设置它。

返回 0 表示 `/readyz` 可用，且只读状态端点返回新进程自己的 PID 和 running 状态。它不是长期服务的退出码。独立完成记录保留 `childExitCode:null` 表示服务仍运行；只有实际退出时记录真实子进程退出码。服务日志和完成记录位于设置文件所在目录，以 UUID 命名。

失败时返回非零，保留日志路径、超时、子进程实际退出码和回收状态。启动失败只回收本次创建的进程；端口占用或身份不符时不结束原端口所有者。原子保存失败也结束本次尚未交付的服务。原生桥接异常无法确定服务状态时返回 `recoveryRequired:true / cleanupConfirmed:false`，携带 UUID 关联的原始记录、日志与独立恢复记录路径；已有启动记录不被重标，PID 只是人工核对线索，不能当作已回收或自动杀 PID。正常 Windows 返回也包含原生启动器退出码和启动器总耗时，它们不等于服务退出码和内部就绪耗时。

## 时间、输出和回滚边界

就绪预算覆盖网关启动和 HTTP 确认。HTTP 单次等待最多 1 秒，响应最多 64 KiB；正常失败回收最多额外 5 秒。Windows 原生桥接等待为就绪预算加 10 秒，外层等待加 20 秒；这些额外预算不扩大模型任务预算。前台宿主命令最多 60 秒，回收最多 5 秒，两路输出各有最多 5 秒 drain 等待，并保留真实退出码、stdout/stderr 和明确超时信息。

NUL 输入避免等待交互；所有句柄和自有临时文件在结束时释放。网关是长期服务，它的两个独立日志文件没有本次新增的大小或保留期限制，需要运维安排轮转。文件模式为 0600；Windows 实际保护依赖已有状态目录的 ACL 继承，本次没有修改系统或目录 ACL。完成记录和公共启动事件只存元数据，不存 token 或原始提供方输出；独立服务日志仍应作为本机私有资料。

既有升级流程的成功、失败恢复旧版本和维护占用路径须运行真实回归。启动器的失败回收不等同于完整安装回滚；完整回滚仍由已有部署流程负责。本次生产安装和旧失败证据保持原样；旧的挂起命令不被强制结束，不补写它们未知的退出码。

## 验收范围

测试使用独立临时目录与自有 HTTP 服务，覆盖直接和嵌套调用、stderr、stdin EOF、退出码 7、就绪超时、错误 PID、占用端口、缺依赖、坏配置、严格参数、原子记录失败及文件释放。实际运行结果和独立预审/事后审查记录放在本次维护证据目录。本地通过不代表生产已部署。
