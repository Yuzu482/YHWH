# 主代理只负责思考与调度

[简体中文](coordinator-only.md) | [English](coordinator-only.en.md)

YHWH 将主代理作为需求、架构、任务拆分、调度和最终验收中心。当前 Codex 宿主使用 Astra；实际代码、测试和实现脚本由 Pi 子代理编写，默认是 Luna/max。宿主仍可以选择其他主模型。

主代理可以读代码、运行确定性探针和已有测试、编写方案与治理文档，并在核对范围和基线后机械应用子代理补丁。它不能把小修复、测试修复或内联脚本当作直接编码的例外。实现有误时，发回子代理修正。强关联修改交给同一个 worker，而不是为了并行强行拆散。

WSL 模型 worker 默认使用基础文件工具和七个 `yhwh_lsp_*` 工具；写任务另有 `edit`、`write`。旧 `pi-lsp-extension` 不再随模型任务自动加载，避免普通读写触发其语言服务器生命周期。旧 `lsp_*`、`ast_search`、`code_overview` 和 `code_rewrite` 不在该模型工具列表中；确定性直接 LSP/结构路径及宿主兼容路径保留。小范围任务也可由无文件权限的 Luna 根据已授权材料交付补丁，主代理核验后机械应用；这不代表 worker 已修改宿主或运行测试。

子代理不可用、超时或交付不完整时，主代理继续诊断与规划，编码部分保持阻塞，不自动接管。只有后续明确的用户指令才能允许主代理直接编码。已执行或结果不确定的写任务必须先按原 requestId 对账；不能通过换 ID 重试绕过账本。确认零执行的排队取消可以按实际资源重新规划。

Astra 明确禁止反复轮询，包括“等待后查询”、每隔 50/60 秒再查，以及用脚本包装的查询循环。旧版定时兜底许可已撤销。监控卡片和 Pi 本地监管心跳独立刷新；主代理处理独立工作，或使用实际可用的完成等待工具。当前没有专用完成等待接口时，等待真实完成/异常信号、预先确定的任务截止时间或用户主动询问后，再作一次必要查询；不能凭空声称已订阅事件。结果未就绪不允许重新开启循环。完整结果分页和有限的验收检查仍保留，不保证等待零 token。详见 [等待规则](../templates/agent-references/pi-results.md)。

每次实际编码应保留 requestId、角色和模型、结果、补丁范围、验证证据与审查独立性。心跳、确定性工具和状态查询单独计数。任务卡片显示成功不能替代完整结果、格式、清理和补丁验收。主代理本地预审/复核不是独立 reviewer 通过，也不等于运行时完整阶段链。

该约束由主代理指令实施。Pi 的沙箱和契约只能约束经由 Pi 的调用，不能禁用任意客户端自身的所有编辑工具。发布包的模板、技能与工作流目录会携带此策略；现有宿主需同步相关规则。修改仓库不代表运行中的 Pi 已升级，不自动发布或推送。

完整执行约定见 [coordinator-only 策略](../templates/agent-references/coordinator-only.md)。
