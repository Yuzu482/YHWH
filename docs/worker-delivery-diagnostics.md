# 子代理交付诊断

[简体中文](worker-delivery-diagnostics.md) | [English](worker-delivery-diagnostics.en.md)

网关的 `phaseTimings.stream` 提供流事件计数和最近活动信息，帮助区分长时间思考、正文生成、工具执行和结果收尾。该字段随执行进度、终态结果及审计记录传播；既有服务须升级对应模块后才会提供。源码改动不代表本机或 release 已更新。

| 字段 | 含义 |
| --- | --- |
| `thinkingDeltas` / `textDeltas` | 观察到的思考 / 正文增量事件数，不是 token 数 |
| `toolStarts` / `toolEnds` / `toolErrors` | 工具开始 / 结束 / 明确报错的结束事件数 |
| `firstTextMs` | 首次正文事件相对于沙箱执行启动的毫秒数；尚未观察到时为 null |
| `lastEventMs` | 最近已识别事件相对于同一启动点的毫秒数；无事件时为 null |
| `lastEventType` | 最近的固定事件类型；不包含工具名称或内容 |

只有显式正文增量，或含非空文本的助手结束消息，才会建立 `firstTextMs`。未收到 `agent_end` 时 `generationMs` 仍为 null。最后活动信息不证明当前远端模型仍健康；思考增量也不证明已经生成可交付代码。事件计数不等于模型调用数，重试和多轮调用仍需独立证据。

新增字段只保存计数、时间和允许的事件类型，不保存提示词、原始思考、正文、工具参数、工具结果或凭据。未知事件被忽略；快照返回计数副本。解析器继续按现有大小限制处理分片 JSON，不增加计时器或模型请求。

总执行时限仍包含认证、启动、模型与工具、进程退出及清理；本改动没有自动延长预算或改变成功判定。调度器超时可能替换执行结果，但最近的阶段元数据可用于诊断。旧记录缺失统计时应视为未知：旧版审计中的工具 total:0/errors:0 可能只是缺省值，不能证明零调用或零错误。

主代理继续遵守禁止反复轮询规则。诊断字段不是完成等待接口，不自动唤醒主代理、取消任务、重试、切换模型或接管编码。完成等待及受控交付模板需分别实现和验收。

确定性测试覆盖思考与正文区分、工具结果、未知事件、无原始内容、快照隔离、分片输入、关闭后统计保留和缺失完成事件。这些测试不等于真实模型超时根因已被完整定位，也不代替部署后的有限实测。
